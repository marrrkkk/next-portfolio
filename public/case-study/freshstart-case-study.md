# FreshStart PH

**Agency website · Actively maintained**

## Overview

FreshStart PH is a web development agency establishing its online presence. I designed and built the website to clearly communicate the agency's services, point of view, and working process, while creating a practical foundation for future work and conversations with prospective clients.

## Design

The visual direction combines warm off-white surfaces, dark editorial sections, and a focused orange accent to give the site a confident but approachable identity. Apfel Grotezk is used for expressive display headings, paired with Geist for readable interface copy. The layout uses generous spacing and clear content groupings to support scanning across desktop and mobile. Responsive compositions, hover states, scroll reveals, and subtle hero motion add rhythm without competing with the content. Motion also respects reduced-motion preferences.

## Engineering

The site is built with Next.js 16, React, TypeScript, and Tailwind CSS. Framer Motion powers selected interface transitions, while Lenis provides smooth scrolling with a reduced-motion fallback. Next.js metadata and JSON-LD structured data support SEO and sharing. Semantic landmarks, labelled navigation, keyboard focus styles, and descriptive image text support accessibility. Local font loading, optimized images, static route generation, and a lightweight IntersectionObserver reveal system help keep the experience fast and maintainable.

## Outcome

This project demonstrates my ability to take an agency from visual direction through responsive UX and production implementation. It shows how I approach brand expression, interaction design, accessibility, performance, and maintainable frontend architecture as one connected process. The outcome is a polished agency website, not a claim of client traction or measured business results.
